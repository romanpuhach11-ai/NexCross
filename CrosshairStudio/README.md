# Crosshair Studio — версія 1.0

WPF-застосунок на C# і .NET 8 для налаштовуваного приціла поверх ігрових і інших вікон.

## Функціональність

- головний Launcher з банером і навігацією до Studio, Presets і Settings;
- прозорий оверлей у borderless/віконному режимі;
- форми приціла: точка, коло, квадрат, хрест і T;
- розмір, товщина, обводка, прозорість і зсув X/Y;
- пульсація, анімація віддачі та градієнтна заливка;
- вибір монітора, пресети у JSON і власні зображення;
- значок у треї та окремий лаунчер;
- перевірка оновлень через останній GitHub Release;
- завантаження portable ZIP із перевіркою SHA-256 перед застосуванням.

## Запуск із вихідного коду

Потрібні Windows 10/11 і .NET 8 SDK.

```powershell
cd CrosshairStudio
dotnet restore
dotnet run --project CrosshairStudio.csproj
```

У Visual Studio 2022 можна відкрити `CrosshairStudio.csproj` і натиснути F5.

## Збірка релізу

```powershell
.\build-release.ps1
```

Скрипт створює автономну публікацію в `publish`, ZIP у `release\CrosshairStudio-1.0.0-win-x64.zip` і контрольні суми в `release\checksums.txt`.

## Установлення та видалення

```powershell
.\install.ps1
.\uninstall.ps1
```

Установлення копіює програму в `%LocalAppData%\CrosshairStudio`, додає ярлик і запис до реєстру видалення Windows.

## Гарячі клавіші

- `Ctrl+Alt+X` — показати або приховати оверлей;
- `Ctrl+Alt+Z` — наступний пресет.

Хрестик головного вікна приховує застосунок у трей. Для повного виходу скористайтеся меню значка в треї.

## Де зберігаються дані

- пресети: `%LocalAppData%\CrosshairStudio\Presets`;
- зображення: `%LocalAppData%\CrosshairStudio\Images`.

## Оновлення

Кнопка «Перевірити оновлення» і перевірка під час запуску звертаються до GitHub Releases у репозиторії `romanpuhach11-ai/NexCross`. Завантаження відбувається лише після підтвердження користувача. Перед оновленням архів перевіряється за SHA-256 із файлу `checksums.txt`, після чого portable-сборка запускається за допомогою тимчасового оновлювача.

## Обмеження та античіти

Оверлей працює в віконному та borderless-режимі й може бути невидимим у exclusive fullscreen, над вікнами з вищими правами або в застосунках із блокуванням сторонніх графічних шарів.

Не обходьте обмеження античитів і перевіряйте правила конкретної гри. Crosshair Studio не змінює ігрові процеси чи пам’ять, але сторонній оверлей може бути заборонений і спричинити попередження або блокування.
